# Featured Projects

## UniTix

**Digital infrastructure for university communities.**

UniTix is a platform designed to modernize how universities, student societies, organizers, and students manage events and campus activities.

### Areas of development

- Digital ticketing and registrations
- QR-based ticket verification
- Offline-first event scanning
- Peer-to-peer and mesh-based capabilities
- Society and organizer management
- Financial records and payouts
- Event analytics and operational tools
- Scalable backend and cloud infrastructure
